### `> about`

</div>

Most of my projects start as experiments — something I wanted to exist but couldn't find.
A few of them evolved into tools other people started using too.

I'm not chasing a stack. I pick what ships the thing faster.
Currently focused on full-stack web development, small utilities, and open-source work.
